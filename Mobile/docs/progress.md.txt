## Next Recommended Task

**Home — Collections section (P1 #2)**

The banner observer already runs `viewModel.getCollections().observe(...)` in
`HomeFragment.observeData()`. The same observer delivers the full `List<CollectionDto>`
including `id`, `name`, and `slug` — everything needed to render a tappable
collections row.

What the implementation requires:
1. **New file** `item_collection.xml` — a card showing `bannerUrl` image + `name`
   label (similar in shape to `item_category.xml`)
2. **New class** `CollectionAdapter` — `ListAdapter<CollectionDto, VH>` following
   the exact same pattern as `CategoryAdapter`
3. **`fragment_home.xml`** — add section label "Bộ sưu tập" and a horizontal
   `RecyclerView` (`rvCollections`) below "Sản phẩm nổi bật"
4. **`HomeFragment.java`** — add `CollectionAdapter collectionAdapter` field;
   set it up in `setupRecyclerViews()`; feed it from the existing
   `getCollections()` observer (already active — just add `collectionAdapter.submitList(...)`)

Tap action: navigate to `productListFragment` with a `collectionId` argument.
`ProductListViewModel.filterByCollection(String)` is already implemented.

Estimated effort: Low (< 1 hour). Zero new API calls. Zero ViewModel changes.
